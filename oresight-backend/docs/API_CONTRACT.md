### POST `/equipment/{equipment_id}/status`

Update an equipment's status

**Query/path params:**

- `equipment_id` (path, `integer`, required)

**Request body:**

- `status` (`'up' | 'down'`, required)
- `reason` (`string | null`, optional)

> Marking equipment 'down' also inserts a new equipment_failure risk_events row (visible below in Risk & Graph) - this example shows that real side effect, then the script restores the equipment and deletes the risk event it created so the seeded demo data is untouched.
